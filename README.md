# Progetto: Primi Passi in AI Engineering

Questo repository raccoglie script ed esempi pratici in Python per interagire con i modelli linguistici tramite API, esplorando i fondamenti dell'AI Engineering (chiamate ai modelli, gestione dei prompt e integrazione).

## 🚀 Obiettivi del Progetto
* Imparare a configurare un ambiente di sviluppo Python pulito.
* Testare la connessione e l'interazione con le API di Gemini.
* Comprendere la struttura di base per inviare prompt ed elaborare risposte via codice.

## 🛠️ Requisiti e Strumenti
* **Python** (versione 3.10 o successiva)
* Libreria ufficiale Google GenAI (`google-genai`)
* Una chiave API valida (ottenuta da Google AI Studio)
